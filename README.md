# ORBIT LOG · 使用说明

这是你的个人博客，网址：**https://myvpsroot.top**

## 怎么写博客（发布一篇新文章）

1. 打开 **https://myvpsroot.top/admin**
2. 点 **Sign In with Token**（用令牌登录）
   - 第一次登录时，按页面提示去 GitHub 生成一个令牌（token），粘贴回来就能登进去。
   - 令牌只需要生成一次，之后浏览器会记住。
3. 在「博客文章」里点 **New（新建）**，填标题、日期、标签、正文（空一行 = 分新段落）。
4. 点 **Publish（发布）**。
5. 等大约 1 分钟，刷新 https://myvpsroot.top，新文章就会出现，所有人都能看到。

改文章、删文章也在同一个后台里完成，改完同样等约 1 分钟生效。

## 关于令牌（重要）

- 令牌相当于你博客后台的钥匙，**不要发给任何人**，也不要截图外传。
- 如果怀疑令牌泄露，去 GitHub 设置里把它删掉，再生成一个新的即可。

## 其他说明

- `posts/` 文件夹里 2026-10 开头的是 3 篇示例文章（中英法三语版）。可以在后台删除；
  但不要用后台编辑它们（后台编辑会把三语格式冲掉），想改示例文章的内容找 Muse 改源文件。
- 想改「关于博主」、网站样式、配色等，直接找 Muse 改这个仓库的 `index.html` 就行。
- 网站右下角的齿轮可以切换界面语言：中文 / English / Français。

## 技术备忘（给维护者）

- 托管：Cloudflare Pages 连接本仓库，推送到 `main` 分支自动构建发布。
- 构建命令：`node build.mjs`，输出目录：`dist`。
- 构建脚本会把 `posts/*.json` 汇总成 `dist/posts-index.json`，网站运行时加载它渲染文章列表。
- 后台：Sveltia CMS（`admin/`），GitHub 后端，令牌登录。
